# T3 Code repository work

Before changing this repository, read [the full maintainer guidance](references/maintainer-guidance.md). It contains the detailed multi-surface, provider, development, test, documentation, and contribution rules that used to live in the repository root `AGENTS.md`.

For user-visible web or desktop changes, follow [test-t3-app](../test-t3-app/SKILL.md). For native mobile changes, follow [test-t3-mobile](../test-t3-mobile/SKILL.md). Do not switch to another UI automation system if the required T3 verification surface is unavailable.
